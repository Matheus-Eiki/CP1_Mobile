## Pré-requisitos

Para executar este projeto localmente, é necessário ter instalado:
* [Node.js](https://nodejs.org/)
* Gerenciador de pacotes (npm ou yarn)
* Aplicativo [Expo Go](https://expo.dev/client) no dispositivo móvel (ou emulador Android/iOS configurado)

## Execução

1. Instale as dependências do repositório:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npx expo start
   ```

3. Leia o QR Code no terminal utilizando o Expo Go no seu dispositivo móvel, ou pressione `a` para abrir no emulador Android e `i` para o simulador iOS.
